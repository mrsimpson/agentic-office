Administration (system admin or tenant admin)

The commands of the group “Administration (system admin or tenant admin)”. The text of each command is the output of office help <command>.

admin key add

Section titled “admin key add”

add a public key to a user.

admin key revoke

Section titled “admin key revoke”

revoke a key; its tokens stop working at once.

admin link

Section titled “admin link”

print a link that opens the admin view in a browser.

admin member list

Section titled “admin member list”

list the members of a tenant.

admin member remove

Section titled “admin member remove”

end the membership of a user in a tenant.

admin member set

Section titled “admin member set”

add a user to a tenant or change its role.

admin system-admin add

Section titled “admin system-admin add”

make a human user a system admin.

admin system-admin remove

Section titled “admin system-admin remove”

take the system admin role away.

admin tenant create

Section titled “admin tenant create”

create a tenant and name its first tenant admin.

admin tenant list

Section titled “admin tenant list”

list the tenants.

admin tenant remove

Section titled “admin tenant remove”

end a tenant.

admin user create

Section titled “admin user create”

register a user with its first public key.

admin user list

Section titled “admin user list”

list all users, also the removed ones.

admin user remove

Section titled “admin user remove”

end a user and its memberships.
