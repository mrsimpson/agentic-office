Hubs and configuration

The commands of the group “Hubs and configuration”. The text of each command is the output of office help <command>.

config show

Section titled “config show”

show the effective settings and where each comes from.

hub add

Section titled “hub add”

add a hub profile and trust the certificate of the hub.

hub list

Section titled “hub list”

list the hub profiles.

hub remove

Section titled “hub remove”

remove a hub profile and its stored certificate.
