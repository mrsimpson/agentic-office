Command reference

This reference comes from the programs themselves. The build of this site runs office help, office help <command>, office help <topic> and office-hub -h and prints what they say, so the reference cannot differ from the programs.

The command line explains itself in the same way:

  • office help lists the commands.
  • office <command> --help shows the purpose, the flags with their defaults and an example.
  • office help <topic> explains a topic.
  • office-hub -h explains the hub.

Commands of office

Section titled “Commands of office”

  • Keys and identity: key create, key show, whoami

  • Hubs and configuration: config show, hub add, hub list, hub remove

  • Meeting: hand raise, meeting end, meeting events, meeting join, meeting leave, meeting log, meeting pause, meeting resume, meeting view, minutes update, say, signal addressed, signal silence-long, signal turn-end, utterance off-the-record

  • Speech and vocabulary: models download, models list, vocabulary extract

  • Stage, portal, slides and documents: document change, document create, document get, document list, portal link, slides get, slides render, stage focus, stage link

  • Decisions, notes, minutes and tasks: decision list, decision record, minutes list, minutes show, note add, note list, task create, task get, task list, task update

  • Import: session import

  • Agents: agent run, mcp

  • Administration (system admin or tenant admin): admin key add, admin key revoke, admin member list, admin member remove, admin member set, admin system-admin add, admin system-admin remove, admin tenant create, admin tenant list, admin tenant remove, admin user create, admin user list, admin user remove

  • Other: help, replicator run, version

  • Artifacts in a local directory: sync, sync credential, sync follow, sync init

  • Topics: config, deck-format, ears, import-format, json
